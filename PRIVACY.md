# Privacy Policy

CourseMOS PDF Viewer processes data locally in your browser to open PDF links in new tabs and display PDF responses inline.

## Data handled locally

The extension stores its ON/OFF preference and the sites you authorize using Chrome's local extension storage and site permissions. It reads the current tab's URL when you open the popup to let you add that site. On authorized sites, it inspects clicked link attributes to identify PDFs and changes PDF response headers using Chrome's declarative network request API.

## Collection and sharing

The extension does not send browsing history, URLs, PDF contents, or settings to the developer or any third party. It contains no analytics, advertising, tracking, or remote executable code. It does not read PDF contents. Your browser still communicates with the sites you visit as part of normal browsing.

## Control and deletion

You can switch the extension OFF, remove optional sites in its popup, or revoke site access in Chrome's extension settings. Uninstalling the extension removes its local extension settings and permissions.
